## Release v1.0.0 - Feature Overview

**EA-H-system** is an agile-based Teaching Assistant recruitment platform developed for **BUPT International School**. Built with **Java Servlet + JSP** technology stack, it implements complete hiring workflows for three core user roles:

| Role | Responsibilities |
|------|----------------|
| **TA (Teaching Assistant Applicant)** | Account registration, browsing job postings, submitting applications, tracking application status |
| **MO (Module Organizer)** | Posting and managing job positions, reviewing TA applications, making hiring decisions |
| **Admin (System Administrator)** | User management, job posting oversight, data maintenance |

### Technical Highlights
- **Data Storage**: Local text-based storage using **JSON** files
- **State Management**: Login sessions managed via **Session/Cookie** mechanism
- **Visualization**: Job matching degree visualization support
